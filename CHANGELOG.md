# Changelog

## 1.0.0

- Initial release of Tategaki Lite: `TategakiLabelLite`, a free Control node
  for basic vertical (tategaki) Japanese text -- right-to-left columns,
  top-to-bottom characters, `\n` hard column breaks, automatic column
  wrapping, and the font's `vert`/`vrt2` vertical punctuation forms.
- Not included (see the full "Tategaki" addon): kinsoku line rules, rotated
  half-width Latin/digits, `[tcy]..[/tcy]` tate-chu-yoko, ruby (furigana) /
  emphasis dots, and the typewriter reveal / `get_overflow()` pagination.
